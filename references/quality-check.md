# 成品验收

检查实际导出的每张图，而非只检查生成提示词。

| 项目 | 通过条件 | 不通过时 |
| --- | --- | --- |
| 文字准确 | 与本次确定的主／副标题逐字一致，无错字、重复字、乱码或遗漏 | 局部改字；工具允许时可对背景图进行确定性文字排版，使用可用且许可适当的字体 |
| 主题突出 | 主标题是最先读到的信息，背景和装饰不抢读 | 放大标题，减少装饰，简化背景 |
| 缩略图可读 | 模拟约 180px 宽的列表预览，主标题可直接读懂，要求保留的副标题也无需放大才能辨认 | 增大文字或重新分行；不要未经允许删除副标题 |
| 人物 | 与来源照片相貌一致，没有明显手指／五官畸变，关键部位未被裁断或遮挡 | 修正人物局部或换用另一张用户照片 |
| 边缘与遮挡 | 标题和重要元素离边缘有余量 | 默认从约 5% 边距开始检查；按用户提供的真实平台截图调整，不把该经验值称为官方安全区 |
| 双画幅 | 对应文件分别是 1080×1440 和 1440×1080，或用户指定尺寸，且各自布局完整 | 同比例才等比缩放；否则重排构图 |
| 文件 | 文件可打开，格式与扩展名一致，下载路径有效，非两张封面拼在同一张图 | 重新导出缺失或损坏的文件 |

180px 缩略图是内部可读性测试尺寸，不代表平台实际显示尺寸。人工／模型视觉检查存在局限；未进行真实用户测试时，不宣称已证明点击率提高或人人都能一眼读懂。

如果环境支持 OCR，可辅助查字，但仍需看图；OCR 通过不能证明字距、对比度、人物或排版通过。不能查看图片时，明确标记“未视觉验收”。

横版和竖版均通过后，交付两张独立图片。若用户只请求单画幅，按其请求验收，不补造额外交付。
